# To-Do List App

A simple to-do list application with local storage support.

## Features

- Add tasks
- Mark tasks as complete
- Delete tasks
- Clear completed tasks
- Persist tasks using browser `localStorage`

## Run locally

Open `index.html` in a browser, or use a local HTTP server:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```
